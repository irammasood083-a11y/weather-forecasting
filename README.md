# Weather Forecast App
A simple and user-friendly Weather Forecasting Web Application built using **HTML, CSS, and JavaScript**.
This application uses a Weather API to display current weather information and a 5-day weather forecast for different cities.

## Features
- Search weather by city name.
- Display current weather conditions.
- Show temperature and other weather details.
- Get weather forecasts for the next 5 days.
- Fetch real-time weather data using an API.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Weather API

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Search for a city to check its weather.
